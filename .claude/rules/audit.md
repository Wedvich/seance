# Audit origins

Every spawn, despawn and reap path audits through its one formatter under its own origin. **A new surface
adds an origin, never reuses one.** No audit line carries prompt or message text (CLAUDE.md, "Text never
reaches a log").

| Origin         | For                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `relay`        | Requests over the relay                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `local`        | Requests on the local op socket                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `local-broker` | Requests the daemon forwards to other machines, or makes of the scheduler (enqueue, queue, cancel, run-now, account list), for a keyless `seance mcp`, `seance spawn` or `seance start`                                                                                                                                                                                                                                                                                                         |
| `schedule`     | The daemon's reap timer                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `probe`        | The daemon's trait probes                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `harvest`      | The daemon closing a dead task pane after noting its exit status                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `handoff`      | The daemon closing a session that handed its PR off (`hand_off_task`)                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `drain`        | The daemon typing its constant drain prompt, or the Escape before it, into a pane of a closed machine                                                                                                                                                                                                                                                                                                                                                                                           |
| `custodian`    | The daemon's seat starting, closing, refusing to start or ending a custodian round, and a round's `close` and the worktree it decides, its `flag`, `nudge` and `interrupt`                                                                                                                                                                                                                                                                                                                      |
| `message`      | A session's message to another task, on this machine or routed through the leader: one `dir=out` and one `dir=in` line per message, and a `dir=receipt` line for the leader's receipt (task ids, kind, byte count and outcome, never text); a custodian nudge writes only its `dir=in` line, `from=custodian`                                                                                                                                                                                   |
| `watch`        | The daemon's watch table adding, removing, noting and ending a GitHub watch: one line per act, closed-enum values only (op, kind, event, reason, outcome) — never a URL, owner, repo, number, head, check name or watch id                                                                                                                                                                                                                                                                      |
| `keep-open`    | The daemon's keep-open table taking a session's hold or release (`keep_session_open`) or dropping a hold whose `claude` is gone: `op` and an outcome only, never a pane, task or session id                                                                                                                                                                                                                                                                                                     |
| `adapter`      | The daemon starting, restarting, refusing, holding as `failed` and stopping a configured adapter (its name, `argv`'s word count and `argv[0]`'s basename, an exit code and a reason, never another argv word or anything the adapter wrote); and each message an adapter delivers or a session sends one (`op=deliver dir=in`, `op=message dir=out`: a task id or the constant `session`/`reply`, kind, byte count, outcome and code, never text, a `from` label, a message or conversation id) |
| `successor`    | The daemon pushing a task's branch on its own session's `pass_to_successor` and closing that session once the leader confirmed it                                                                                                                                                                                                                                                                                                                                                               |
| `leader`       | The scheduler loop dispatching to its own machine in process and admitting a task                                                                                                                                                                                                                                                                                                                                                                                                               |
| `mcp`          | `seance mcp`'s own `spawn_session`/`queue_batch`/`continue_task` enqueue lines                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `cli`          | Anything typed at this machine's shell, its `spawn` enqueue line included                                                                                                                                                                                                                                                                                                                                                                                                                       |
